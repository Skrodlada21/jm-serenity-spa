# Polo shirt embroidery artwork

One thread colour. No silhouette. Lettering matched to the logo and converted
to outlines, so no font is needed to render or digitise these files.

## Lettering
- **J&M** — Cormorant Garamond SemiBold Italic  (`-serif` files)
- **J&M** — Great Vibes, closer to the logo but softer at small sizes (`-script` files)
- **Serenity Spa** — Great Vibes, in both variants

Both fonts are SIL Open Font Licence: free to use on merchandise, nothing to buy.
Brittany Signature also suits Serenity Spa but is a commercial font, so it is not used here.

## Layouts
- `jm-polo-chest-*`    left chest, wide and shallow — RECOMMENDED for polos
- `jm-polo-stacked-*`  lotus above the name, crest-like — also good on caps and bags
- `jm-polo-script-*`   name and flourish only, no lotus — fewest stitches, cheapest

## Colours
| Garment | Thread | Hex |
|---|---|---|
| White polo | Navy | `#1E2340` |
| Navy polo | Cream | `#F4F1EA` |
| Navy polo | Gold | `#C9A227` |

The plain `jm-polo-*.svg` files carry the colour as a CSS variable, so one file
serves every garment. The `-navy` / `-cream` / `-gold` copies have it baked in —
those are the ones to email out.

## Ordering
- Width **4.0 in (102 mm)**; do not go below 3.5 in — the script hairlines are
  the limiting factor, not the lotus.
- Placement: left chest, wearer's left, ~7-8 in below the shoulder seam.
- Satin stitch the lettering, run stitch the lotus outline.
- Tell the digitiser to set a **minimum stitch width** so the hairlines do not drop out.
- Ask for a sew-out on the real polo fabric before the full run.
